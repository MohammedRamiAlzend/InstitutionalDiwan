# خيارات الحقول الديناميكية (سلوك الإدخال والجداول)

> **الحالة: منفّذة (2026-11-08).** `dotnet test` 828 ناجح، و`npm run build` و`npm run lint` ناجحان، وجُرّبت على API حي وSQL Server مؤقت ومن المتصفح. لم يُجرَّب: الوضع الفاتح والجوال، وترقية قاعدة تحوي حقولًا منشورة فعلًا (الترحيل طُبّق على قاعدة جديدة).

## القرارات المعتمدة من المستخدم

| الموضوع | القرار |
| --- | --- |
| الفلترة | علامة «قابل للتصفية» وتظهر الحقول في شريط الجدول، أعمدة ديناميكية في السجل مع الفرز، وتصفية في الأرشيف وعلى واجهة وثائق الدائرة |
| للقراءة فقط | ثابت على القيمة الافتراضية: يكتبها الخادم ويرفض غيرها، ويشترط وجود قيمة افتراضية |
| القيمة الافتراضية | ثابتة لكل نوع حقل، و«تاريخ اليوم» للتواريخ؛ تُملأ في النموذج ويمكن تغييرها أو مسحها |
| خيارات إضافية | نص توضيحي ومساعدة، طول أدنى، حدود تاريخ، إظهار شرطي، تخطيط (نصف عرض وأقسام)، اختيار متعدد، وقوائم مرتبطة |

## قرارات التصميم

- **`Behavior` عمود JSON واحد** على حقل نسخة المخطط، كعمود الخيارات: لا عمود لكل خيار، والنسخة المنشورة تبقى مجمّدة. الصفوف القائمة تُرحَّل بـ `IsFilterable = true` لأن كل حقل كان متاحًا للتصفية.
- **الاختيار المتعدد** يُخزَّن `|a|b|` في `TextValue`، فلا جدول جديد ولا تغيير على فهرس (مستند + حقل) الفريد، والتصفية `LIKE` مع هروب `_`.
- **القوائم المرتبطة** تُقرأ عند الطلب (`IDocumentFieldOptionResolver`) وتعود في `options` نفسها، فلا تعرف الواجهة مصدرها ولا تستورد شرائح مجاورة. العناصر الموقوفة تعود بعلامة وتبقى مقروءة في الوثائق القديمة. لا قيمة افتراضية للقوائم المرتبطة.
- **الشرط** يعتمد على حقل نعم/لا أو قائمة أو اختيار متعدد فقط (قيم منفصلة). يُفحص عند كل تعديل للمسودة: حقل موجود، قيمة صحيحة، بلا دوران؛ ولا يُحذف حقل يعتمد عليه غيره.
- **الحقل المخفي** لا يُطلب ولا يُحفظ حتى لو أُرسلت له قيمة.
- **«اليوم»** في حدود التاريخ يتسع على الخادم ليوم أوسع منطقة زمنية، لأن المتصفح يختار تاريخًا محليًا والخادم يعرف UTC فقط.
- **`isFilterable`** يحكم الواجهة فقط: يبقى الخادم يقبل التصفية بأي حقل كي لا تنكسر الروابط المشاركة.
- **الفرز** للنص والرقم والتاريخ والمنطقي فقط؛ القوائم تُخزَّن مفاتيح لا عناوين فالفرز عليها بلا معنى.

## خارج النطاق

أعمدة ديناميكية في الأرشيف، وفلترة بالحقول لسجل الدوائر في الواجهة (لا شاشة له)، وشروط على حقول النص والرقم والتاريخ.
