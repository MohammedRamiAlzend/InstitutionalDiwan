# Project Creation & Documentation History

## institutionaldiwan.front (this project)

Created on 2026-10-26 with:

```bash
npm create vite@latest institutionaldiwan.front -- --template react-ts
```

- Stock Vite React 19 + TypeScript 6 + Vite 8 template.
- No proxy, `@` alias, HTTPS dev certificate, `.env`, or Visual Studio `.esproj`.
- FSD documentation kit (root docs, six layer READMEs, and per-slice READMEs) ported from the
  previous client project on 2026-10-26; that project and its solution/server integration have
  since been removed.
- Intended to live as a standalone front end, outside `InstitutionalDiwan.slnx`.
